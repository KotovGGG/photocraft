# Проверка ремонта панелей на PhotoCraft 0.22.0 — 2026-11-10

Код: ветка `codex/panel-layout-v022-review`, коммит `beeea2571655190e176332ec03cb75cf7afa99ba` в fork KotovGGG/photocraft. Основа: тег upstream `v0.22.0`, `5000240c6`; craft-libs `1b34eba41e62138fc2438d2734523b302840b45d`.

## Изменения по отзыву David Mann

- Плавающая Tools не имеет свободного изменения размера. Заголовок переключает одну/две колонки; высота зависит от видимых инструментов и доступной рабочей области.
- У вкладок документов и верхнего/нижнего края холста нет зон закрепления панелей. Отпущенная там панель остаётся плавающей. Закрепление сбоку и над/под другими группами сохранено.
- Старые сохранённые раскладки и метаданные размеров читаются. Старые размеры Tools больше не управляют отображаемой геометрией.
- Новые возможности upstream 0.22.0 сохранены: Home Screen, границы окон документов, варианты выбора инструментов/flyout, GPU-учёт видимых документов и постоянные уведомления.

## Сборка пользователем

Основной продуктовый EXE агент не собирал и не запускал. На этом компьютере:

```powershell
Set-Location 'F:\photocraft-panel-v022'
$env:CARGO_TARGET_DIR = 'F:\photocraft\target'
cargo build --release -p photocraft
if ($LASTEXITCODE -eq 0) { & 'F:\photocraft\target\release\photocraft.exe' }
```

Существующая папка F:/photocraft остаётся на прежней рабочей ветке; собирать новую версию нужно из указанной отдельной папки. На другом компьютере можно клонировать ветку:

```powershell
git clone --branch codex/panel-layout-v022-review https://github.com/KotovGGG/photocraft.git photocraft-panel-v022
cd photocraft-panel-v022
cargo build --release -p photocraft
```

## Что проверить в своём EXE

1. Отделить Tools целиком; проверить переключение одной/двух колонок и отсутствие изменения размеров за края/углы.
2. Перетащить полную и свёрнутую панель над/под строкой вкладок документов: она должна остаться плавающей.
3. Проверить сохранённое закрепление в боковых колонках, над/под другой группой, изменение размеров обычных панелей и сохранение/загрузку раскладки.
4. Проверить выбор инструментов, flyout и двойной клик Hand/Zoom.

Native focus/IME, реальные мониторы, mixed-DPI и GPU-задержки остаются отдельной живой проверкой. PR не объединялись; существующие PR пока не переключены на эту сборку. После пользовательской проверки следует обновить существующий PR, сохранив деление работы на небольшие части.
